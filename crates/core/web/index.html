      Stop the security warning on this device

      Install the computer's certificate once. After that this device gets a verified connection with no warning.

      iPhone and iPad

      1. Tap Download certificate, then Allow and Close.
      2. Open Settings → Profile Downloaded → Install.
      3. Settings → General → About → Certificate Trust Settings → turn on Simple Share local certificate.
      4. Check it is really the computer's: in Settings → General → VPN & Device Management → the profile → More Details, the SHA-256 must match the code on the computer under Settings → Pairing.

      Android

      1. Tap Download certificate.
      2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate, then pick the file.
